# Demo aplikace pro ESP32 pro RatatoskrIoT

## ESP32 s kamerou: Posílání fotek do galerie

Jednoduchá aplikace pro ESP32-CAM (a ESP32S3-CAM a další varianty), která periodicky posílá fotky do galerie.
Aplikace je zde: [Esp32Cam-Simple](Esp32Cam-Simple/)

Popis galerií v dokumentaci: https://ratatoskr.lovecka.info/web/page/galerie


## ESP32 s kamerou: Detekce změn v obraze ("detekce pohybu") a posílání fotek do galerie

Aplikace pro ESP32-CAM (a ESP32S3-CAM a další varianty), která posílá fotky do galerie, když dojde ke změně v obraze.
Aplikace je zde: [Esp32Cam-MotionDetect](Esp32Cam-MotionDetect/)
