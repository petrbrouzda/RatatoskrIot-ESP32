# Demo aplikace pro ESP32 pro RatatoskrIoT

## Posílání fotek do galerie

Jednoduchá aplikace pro ESP32-CAM (a ESP32S3-CAM a další varianty), která periodicky posílá fotky do galerie.
Aplikace je zde: [Esp32Cam-Simple](Esp32Cam-Simple/)

Popis galerií v dokumentaci: https://ratatoskr.lovecka.info/web/page/galerie
